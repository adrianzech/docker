## Required values

| Variable | Value | Generate |
| --- | --- | --- |
| `VNC_URL` | `https://fcg.zech.co` | — |
| `EG_EMAIL`, `EG_PASSWORD`, `EG_OTPKEY` | Optional Epic Games credentials and TOTP key; also used by Fab | Epic Games |
| `UBI_EMAIL`, `UBI_PASSWORD`, `UBI_OTPKEY` | Optional Ubisoft credentials and TOTP key | Ubisoft |
| `STEAM_USERNAME`, `STEAM_PASSWORD` | Optional Steam credentials | Steam |
| `GOG_EMAIL`, `GOG_PASSWORD`, `GOG_OTP_CODES` | Optional GOG credentials and backup codes | GOG |
| `PG_EMAIL`, `PG_PASSWORD`, `PG_OTPKEY` | Optional Amazon Prime Gaming credentials and TOTP key | Amazon |
| `NOTIFY` | Pushover Apprise URL: `pover://{user_key}@{api_token}` | Pushover |
| `STORES` | `steam,epic,fab,prime,gog,ubisoft` | — |
